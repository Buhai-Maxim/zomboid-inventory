# 🧟 Zomboid Inventory System

Навчальний проєкт системи обліку та управління інвентарем з використанням Python, FastAPI та React.

## 📌 Функціонал
- **Storage Layer**: ООП-модуль для читання CSV-файлів та управління даними предметів.
- **CLI Utility**: Консольний інтерфейс для перегляду статистики станів предметів та пошуку.
- **REST API**: Повноцінний API на FastAPI з ендпоінтами для пагінації, пошуку та отримання статистики.
- **Frontend**: Веб-інтерфейс на React (CDN) з підсвіткою станів предметів (Mint, New, Good).
- **Unit Testing**: Набір автоматичних тестів з використанням `pytest`.
